## Prototypes you can run

- [tread](https://github.com/CarlHolland93/tread) points a phone at a running
  shoe and scores its wear with Claude vision. It only names the shoe from text
  it can read on it.
- [chat-input-concepts](https://github.com/CarlHolland93/chat-input-concepts)
  is four ideas for the chat input box, covering prompt quality, context
  budget, intent and model choice. Nothing calls a model.
